# Missing Board

If you can't find your board here, please check the [Betaflight config repository](https://github.com/betaflight/config/tree/master/configs). Configs are grouped by manufacturer, so look under your manufacturer's four-letter code (see the [manufacturers list](https://github.com/betaflight/config/blob/master/Manufacturers.md)), or search the repository for the board name.

F1, F3 and other older boards are in the [board archive](/docs/category/archive-1)

If a current board is not listed here, please ask the manufacturer to make a pull request as described in our [manufacturer design guidelines](/docs/development/manufacturer/manufacturer-design-guidelines)
